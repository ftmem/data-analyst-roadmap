# تمرین های حل مسئله

تمرین های این بخش برای تقویت مهارت حل مسئله و طراحی الگوریتم هستند.

> ابتدا خودتان الگوریتم را طراحی کنید، سپس پاسخ را بررسی کنید.

## تمرین ۱ — مجموع دو عدد

دو عدد A و B را دریافت کنید و مجموع آن ها را نمایش دهید.

---

## تمرین ۲ — میانگین سه عدد

سه عدد A، B و C را دریافت کنید و میانگین آن ها را محاسبه و نمایش دهید.

---

## تمرین ۳ — مساحت مستطیل

طول و عرض یک مستطیل را دریافت کنید و مساحت آن را محاسبه و نمایش دهید.

فرمول:

`Area = Length × Width`

---

## تمرین ۴ — باقی مانده تقسیم

دو عدد A و B را دریافت کنید و باقی مانده تقسیم A بر B را محاسبه و نمایش دهید.

راهنما:

`A % B`

---

## تمرین ۵ — تشخیص عدد بزرگ تر

دو عدد A و B را دریافت کنید و مشخص کنید کدام یک بزرگ تر است.

> برای حل این تمرین از شرط استفاده کنید.
