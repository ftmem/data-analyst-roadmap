# مهارت حل مسئله

قبل از شروع برنامه‌ نویسی باید یاد بگیریم مسئله را درست بررسی و حل کنیم.

حل مسئله یعنی بتوانیم یک مسئله را از ابتدا تا رسیدن به نتیجه، به مراحل مشخص و قابل اجرا تقسیم کنیم.

## مراحل حل مسئله

### 1. فهمیدن مسئله

اول باید دقیقاً بفهمیم مسئله چیست و چه نتیجه‌ ای از ما می‌ خواهد.

> فهمیدن مسئله، بخش مهمی از حل مسئله است.

### 2. شکستن مسئله به بخش‌ های کوچک‌ تر

اگر مسئله بزرگ یا پیچیده باشد، آن را به چند مسئله کوچک‌ تر تقسیم می‌ کنیم.

هر بخش را جداگانه بررسی و حل می‌ کنیم و در نهایت جواب آن‌ ها را کنار هم قرار می‌ دهیم.

### 3. مشخص کردن ورودی‌ ها

باید مشخص کنیم برای حل مسئله چه اطلاعاتی در اختیار داریم یا چه اطلاعاتی باید دریافت کنیم.

مثال:

- عدد اول
- عدد دوم

### 4. مشخص کردن خروجی

باید بدانیم در پایان چه نتیجه‌ای باید تولید شود.

مثال:

- مجموع دو عدد

### 5. پیدا کردن راه‌ حل

ممکن است یک مسئله چند روش مختلف برای حل داشته باشد.

روش‌ های مختلف را بررسی می‌ کنیم و با توجه به شرایط، روش مناسب را انتخاب می‌ کنیم.

### 6. نوشتن مراحل حل

راه‌ حل انتخاب‌ شده را به صورت مرحله‌ به‌ مرحله و دقیق می‌ نویسیم تا قابل اجرا باشد.

### 7. بررسی و اشکال‌ زدایی

در پایان باید بررسی کنیم که راه‌ حل برای حالت‌ ها و ورودی‌ های مختلف درست کار می‌ کند یا نه.

اگر مشکلی وجود داشت، آن را پیدا و اصلاح می‌ کنیم.

---

## خلاصه

برای حل یک مسئله:

1. مسئله را بفهم.
2. مسئله را به بخش‌ های کوچک‌تر تقسیم کن.
3. ورودی‌ ها را مشخص کن.
4. خروجی مورد انتظار را مشخص کن.
5. راه‌ حل مناسب را پیدا کن.
6. مراحل حل را به ترتیب بنویس.
7. راه‌ حل را بررسی و اشکال‌ زدایی کن.




# الگوریتم چیست؟

الگوریتم مجموعه ای از دستورالعمل های دقیق و مرحله به مرحله است که از یک شروع مشخص آغاز می شود و با انجام مراحل مشخص، ما را به یک نتیجه مطلوب می رساند.

یک الگوریتم باید برای اجراکننده قابل فهم و قابل اجرا باشد.

## ویژگی های الگوریتم

- شروع مشخص دارد.
- پایان مشخص دارد.
- مراحل آن دقیق و قابل فهم هستند.
- قابل اجرا برای مخاطب است.
- ورودی ها را دریافت می کند.
- روی ورودی ها پردازش انجام می دهد.
- خروجی موردنظر را تولید می کند.

## ساختار کلی الگوریتم

شروع → ورودی → پردازش → خروجی → پایان

## مثال: جمع دو عدد

1. شروع
2. دریافت عدد اول
3. دریافت عدد دوم
4. جمع کردن دو عدد
5. نمایش نتیجه
6. پایان




## ورودی، پردازش و خروجی

هر مسئله را می توانیم به سه بخش اصلی تقسیم کنیم:

### 1. ورودی (Input)

اطلاعاتی که برای حل مسئله نیاز داریم یا از کاربر دریافت می کنیم.

مثال:

- عدد اول
- عدد دوم

### 2. پردازش (Process)

عملیاتی که روی ورودی ها انجام می دهیم تا به نتیجه برسیم.

مثال:

text
C = A + B
### 3. خروجی (Output)

نتیجه ای که بعد از پردازش به دست می آید.

مثال:

text
C
### مثال کامل

مسئله: دو عدد را دریافت کن و مجموع آن ها را نمایش بده.

text
Input:
A
B

Process:
C = A + B

Output:
C
### خلاصه

text
Input → Process → Output
## عملگرهای حسابی

برای انجام محاسبات ریاضی در حل مسائل از عملگرهای حسابی استفاده می کنیم.

| عملگر | معنی |
|---|---|
| `+` | جمع |
| `-` | تفریق |
| `*` | ضرب |
| `/` | تقسیم |
| `%` | باقی مانده تقسیم |

### مثال

```text
A = 10
B = 3

A + B = 13
A - B = 7
A * B = 30
A / B = 3.333...
A % B = 1
```

## ترتیب انجام عملیات

در یک عبارت ریاضی، عملیات طبق ترتیب مشخصی انجام می شوند.

به طور کلی:

1. پرانتز
2. ضرب و تقسیم
3. جمع و تفریق

### مثال

```text
A = 2 + 3 * 4
```

ابتدا ضرب انجام می شود:

```text
3 * 4 = 12
```

سپس جمع انجام می شود:

```text
2 + 12 = 14
```

پس نتیجه:

```text
A = 14
```

### استفاده از پرانتز

برای تغییر ترتیب انجام عملیات از پرانتز استفاده می کنیم.

```text
A = (2 + 3) * 4
```

ابتدا داخل پرانتز محاسبه می شود:

```text
2 + 3 = 5
```

سپس ضرب انجام می شود:

```text
5 * 4 = 20
```

پس نتیجه:

```text
A = 20
```

## الگوریتم چیست؟

الگوریتم مجموعه ای از دستورالعمل های دقیق و مرحله به مرحله برای حل یک مسئله است.

یک الگوریتم باید به گونه ای نوشته شود که انجام دهنده بتواند مراحل آن را به درستی اجرا کند.

### ویژگی های یک الگوریتم

یک الگوریتم مناسب باید:

- دقیق و مشخص باشد.
- قابل فهم باشد.
- مراحل آن قابل اجرا باشند.
- شروع مشخص داشته باشد.
- پایان مشخص داشته باشد.

### مثال ساده

**مسئله:** مجموع دو عدد را به دست آورید.

مراحل الگوریتم:

1. شروع
2. عدد اول را دریافت کن.
3. عدد دوم را دریافت کن.
4. دو عدد را با هم جمع کن.
5. نتیجه را نمایش بده.
6. پایان

به صورت خلاصه:

```text
Start
  ↓
Input A
  ↓
Input B
  ↓
C = A + B
  ↓
Output C
  ↓
End
```

## مراحل طراحی یک الگوریتم

برای حل یک مسئله می توانیم این مراحل را طی کنیم:

1. مسئله را به طور کامل درک کنیم.
2. مسئله را به بخش های کوچک تر تقسیم کنیم.
3. ورودی ها و خروجی ها را مشخص کنیم.
4. راه حل های مختلف را بررسی کنیم.
5. بهترین راه حل را انتخاب کنیم.
6. مراحل حل را به ترتیب بنویسیم.
7. الگوریتم را با ورودی های مختلف آزمایش کنیم.
8. خطاهای احتمالی را پیدا و اصلاح کنیم.
## انواع دستورها در الگوریتم

در یک الگوریتم، دستورهایی که اجرا می کنیم معمولاً شامل چند نوع اصلی هستند:

### 1. دستور ورودی (Input)

برای دریافت اطلاعات مورد نیاز مسئله استفاده می شود.

مثال:

```text
دریافت عدد A
دریافت عدد B
```

### 2. دستور خروجی (Output)

برای نمایش یا ارائه نتیجه استفاده می شود.

مثال:

```text
نمایش C
```

### 3. دستور پردازش (Process)

برای انجام محاسبات یا عملیات روی داده ها استفاده می شود.

مثال:

```text
C = A + B
```

### 4. دستور تکرار (Loop)

برای انجام چندباره یک دستور یا مجموعه ای از دستورها استفاده می شود.

مثال:

```text
تکرار 5 بار:
    نمایش عدد
```

### 5. دستور شرطی (Condition)

برای تصمیم گیری بر اساس یک شرط استفاده می شود.

مثال:

```text
اگر A > B باشد:
    A را نمایش بده
در غیر این صورت:
    B را نمایش بده
```

### خلاصه

```text
Input       → دریافت اطلاعات
Process     → پردازش اطلاعات
Output      → نمایش نتیجه
Loop        → تکرار دستورها
Condition   → تصمیم گیری
```
## فلوچارت (Flowchart)

فلوچارت نمایش تصویری مراحل یک الگوریتم است.

با استفاده از فلوچارت می توانیم مراحل حل یک مسئله را به شکل ساده و قابل فهم نمایش دهیم.

### نمادهای اصلی فلوچارت

| نماد | کاربرد |
|---|---|
| بیضی | شروع و پایان |
| متوازی الاضلاع | ورودی و خروجی |
| مستطیل | پردازش |
| لوزی | شرط و تصمیم گیری |
| فلش | مشخص کردن مسیر اجرای الگوریتم |
| دایره کوچک | اتصال بخش های مختلف فلوچارت |

### شروع و پایان

برای مشخص کردن شروع و پایان الگوریتم از نماد **بیضی** استفاده می کنیم.

```text
Start
  ↓
...
  ↓
End
```

### ورودی و خروجی

برای دریافت ورودی یا نمایش خروجی از نماد **متوازی الاضلاع** استفاده می کنیم.

```text
Input A
  ↓
Output A
```

### پردازش

برای انجام محاسبات و عملیات از **مستطیل** استفاده می کنیم.

```text
C = A + B
```

### شرط

برای بررسی یک شرط و تصمیم گیری از **لوزی** استفاده می کنیم.

```text
A > B ?
```

اگر شرط درست باشد، مسیر مربوط به **بله (Yes)** و اگر نادرست باشد، مسیر **خیر (No)** دنبال می شود.

### مثال ساده

برای مسئله «دو عدد را دریافت کن و مجموع آن ها را نمایش بده»:

```text
Start
  ↓
Input A
  ↓
Input B
  ↓
C = A + B
  ↓
Output C
  ↓
End
```

### خلاصه

```text
Start
  ↓
Input
  ↓
Process
  ↓
Output
  ↓
End
```

## مثال عملی: محاسبه میانگین دو عدد

**مسئله:** دو عدد را دریافت کنید و میانگین آن ها را محاسبه و نمایش دهید.

### ورودی

دو عدد `A` و `B`

### پردازش

ابتدا دو عدد را با هم جمع می کنیم:

```text
C = A + B
```

سپس مجموع را بر 2 تقسیم می کنیم:

```text
Average = C / 2
```

### خروجی

میانگین دو عدد را نمایش می دهیم.

### الگوریتم

1. شروع
2. عدد اول را دریافت کن.
3. عدد دوم را دریافت کن.
4. دو عدد را با هم جمع کن.
5. حاصل جمع را بر 2 تقسیم کن.
6. میانگین را نمایش بده.
7. پایان

### نمایش به صورت Input → Process → Output

```text
Input:
A
B

Process:
C = A + B
Average = C / 2

Output:
Average
```

### مثال

اگر:

```text
A = 10
B = 20
```

ابتدا:

```text
C = 10 + 20
C = 30
```

سپس:

```text
Average = 30 / 2
Average = 15
```

بنابراین خروجی:

```text
15
```

## جمع بندی

برای حل یک مسئله قبل از نوشتن کد باید:

1. مسئله را به درستی درک کنیم.
2. آن را به بخش های کوچک تر تقسیم کنیم.
3. ورودی و خروجی را مشخص کنیم.
4. مراحل پردازش را مشخص کنیم.
5. الگوریتم را مرحله به مرحله بنویسیم.
6. الگوریتم را با ورودی های مختلف آزمایش کنیم.
7. خطاها را پیدا و اصلاح کنیم.

به طور کلی:

```text
Problem
   ↓
Input
   ↓
Process
   ↓
Output
   ↓
Test & Debug
```

> قبل از اینکه یک مسئله را با کدنویسی حل کنیم، باید بتوانیم راه حل آن را به صورت مرحله به مرحله توضیح دهیم.
