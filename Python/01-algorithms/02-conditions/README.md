# Conditions

## شرط چیست؟

شرط به برنامه اجازه می دهد یک وضعیت را بررسی کند و بر اساس نتیجه، تصمیم بگیرد.

برای مثال:

اگر سن فرد بزرگ تر یا مساوی 18 باشد، او مجاز است.

```text
Age >= 18
```

اگر شرط درست باشد، یک مسیر اجرا می شود و اگر شرط نادرست باشد، مسیر دیگری اجرا می شود.

## ساختار کلی شرط

```text
If Condition
    دستور در صورت درست بودن شرط

Else
    دستور در صورت نادرست بودن شرط
```

### مثال

```text
If Age >= 18
    Output "مجاز"
Else
    Output "غیرمجاز"
```

## عملگرهای مقایسه ای

| عملگر | معنی |
|---|---|
| `>` | بزرگ تر از |
| `<` | کوچک تر از |
| `>=` | بزرگ تر یا مساوی |
| `<=` | کوچک تر یا مساوی |
| `==` | مساوی |
| `!=` | نامساوی |

## مثال با دو عدد

دو عدد `A` و `B` را دریافت می کنیم و بررسی می کنیم کدام یک بزرگ تر است.

```text
Input A
Input B

If A > B
    Output A
Else
    Output B
```

در این مثال:

- `A > B` شرط است.
- اگر شرط درست باشد، `A` نمایش داده می شود.
- اگر شرط نادرست باشد، `B` نمایش داده می شود.

## شرط در فلوچارت

در فلوچارت، شرط با نماد **لوزی (Diamond)** نمایش داده می شود.

```text
       A > B ?
      /       \
    Yes        No
     ↓          ↓
 Output A   Output B
```

## ساختار کلی

```text
Input
  ↓
Condition
 ↙      ↘
Yes      No
↓         ↓
Action   Action
 ↘       ↙
   Output
     ↓
    End
```
