
# Exercises — Type Conversion and Input

## تمرین 1 — تبدیل String به Integer

رشته ی زیر را به عدد صحیح تبدیل کنید و نوع آن را نمایش دهید:

```python
number = "123"
```

## تمرین 2 — تبدیل String به Float

رشته ی زیر را به عدد اعشاری تبدیل کنید و نوع آن را نمایش دهید:

```python
number = "12.5"
```

---

## تمرین 3 — تفاوت String و Number

خروجی کد زیر را پیش بینی کنید و سپس آن را اجرا کنید:

```python
print(100 * 2)
print("100" * 2)
```

توضیح دهید چرا خروجی ها متفاوت هستند.

## تمرین 15 — ترکیب Input و Type Conversion

برنامه ای بنویسید که:

1. نام کاربر را دریافت کند.
2. سن کاربر را دریافت کند.
3. سن را به `int` تبدیل کند.
4. سن کاربر در سال آینده را محاسبه کند.
5. نتیجه را نمایش دهد.

مثال:

```text
Enter your name:
Fatemeh

Enter your age:
28

Fatemeh will be 29 next year.
```
