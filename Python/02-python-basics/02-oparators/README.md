# Operators

در این بخش با عملگرهای مقایسه ای، منطقی و بیتی در Python آشنا می شویم.

---

## 1. عملگرهای مقایسه ای

عملگرهای مقایسه ای برای مقایسه دو مقدار یا دو متغیر استفاده می شوند.

نتیجه یک مقایسه همیشه یکی از دو مقدار زیر است:

```python
True
False
```

### عملگرهای مقایسه ای

| عملگر | مفهوم |
|---|---|
| `==` | مساوی |
| `!=` | نامساوی |
| `>` | بزرگ تر |
| `<` | کوچک تر |
| `>=` | بزرگ تر یا مساوی |
| `<=` | کوچک تر یا مساوی |

### مثال

```python
x = 3
y = 2

print(x == y)
print(x > y)
print(x < y)
```

خروجی:

```text
False
True
False
```

---

## 2. تفاوت `=` و `==`

این دو علامت کاربرد متفاوتی دارند.

### `=`

برای مقداردهی به متغیر استفاده می شود:

```python
x = 5
```

یعنی مقدار `5` را در متغیر `x` قرار می دهیم.

### `==`

برای مقایسه دو مقدار استفاده می شود:

```python
x == 5
```

یعنی بررسی می کنیم که آیا مقدار `x` برابر با `5` است یا خیر.

---

## 3. نوع داده Boolean

نتیجه عملگرهای مقایسه ای از نوع `bool` است.

نوع `bool` فقط دو مقدار دارد:

```python
True
False
```

مثال:

```python
x = 5

print(x == 5)
print(x > 10)
print(type(x == 5))
```

خروجی:

```text
True
False
<class 'bool'>
```

---

## 4. استفاده از مقایسه ها در برنامه

نتیجه مقایسه می تواند در تصمیم گیری های برنامه استفاده شود.

مثلاً:

```python
number = 5

print(number != 3)
```

چون مقدار `number` برابر 3 نیست، نتیجه `True` است.

مقایسه ها پایه ای برای استفاده از شرط ها و تصمیم گیری در برنامه هستند.

---

# Logical Operators

برای ترکیب یا تغییر نتیجه چند شرط می توانیم از عملگرهای منطقی استفاده کنیم.

## 5. عملگر `and`

عملگر `and` زمانی `True` است که **هر دو شرط True باشند**.

```python
x = 5

print(x > 3 and x < 10)
```

هر دو شرط درست هستند، بنابراین خروجی:

```text
True
```

مثال دیگر:

```python
x = 5

print(x > 3 and x > 10)
```

یکی از شرط ها `False` است، بنابراین نتیجه:

```text
False
```

---

## 6. عملگر `or`

عملگر `or` زمانی `True` است که **حداقل یکی از شرط ها True باشد**.

```python
x = 5

print(x > 10 or x == 5)
```

شرط دوم درست است، بنابراین:

```text
True
```

---

## 7. عملگر `not`

عملگر `not` نتیجه یک عبارت منطقی را برعکس می کند.

```python
x = 5

print(not x == 5)
```

عبارت `x == 5` برابر `True` است.

پس:

```python
not True
```

برابر است با:

```text
False
```

---

## 8. عملگر `xor`

در منطق XOR فقط زمانی نتیجه `True` است که **یکی از دو طرف True و طرف دیگر False باشد**.

در Python از علامت `^` برای XOR استفاده می شود.

برای مقادیر Boolean:

```python
T = True
F = False

print(T ^ F)
print(T ^ T)
print(F ^ F)
```

خروجی:

```text
True
False
False
```

---

# Bitwise Operators

عملگرهای Bitwise روی بیت های عدد کار می کنند.

کامپیوتر اعداد را در سطح پایین به صورت بیت ها، یعنی `0` و `1`، پردازش می کند.

برای مثال:

```text
2 = 10
3 = 11
```

---

## 9. Bitwise AND

عملگر Bitwise AND با علامت `&` نوشته می شود.

هر بیت دو عدد با بیت متناظر خودش مقایسه می شود.

مثال:

```text
  10
& 11
----
  10
```

در Python:

```python
a = 2
b = 3

print(a & b)
```

خروجی:

```text
2
```

---

## 10. Bitwise OR

عملگر Bitwise OR با علامت `|` نوشته می شود.

اگر حداقل یکی از بیت ها `1` باشد، نتیجه آن بیت `1` خواهد بود.

مثال:

```python
a = 2
b = 3

print(a | b)
```

خروجی:

```text
3
```

---

## 11. نمایش عدد در مبنای 2

برای نمایش یک عدد در مبنای 2 می توانیم از `bin()` استفاده کنیم.

مثال:

```python
print(bin(2))
print(bin(3))
```

خروجی:

```text
0b10
0b11
```

`0b` نشان می دهد که مقدار نمایش داده شده در مبنای 2 است.

---

# Shift Operators

عملگرهای Shift برای جابه جایی بیت ها استفاده می شوند.

دو عملگر اصلی داریم:

```text
<<
>>
```

---

## 12. شیفت به چپ `<<`

شیفت به چپ در مبنای 2، معمولاً معادل ضرب عدد در توان های 2 است.

مثال:

```python
x = 5

print(x << 1)
```

خروجی:

```text
10
```

یعنی:

```text
5 × 2 = 10
```

اگر دو بار شیفت بدهیم:

```python
print(x << 2)
```

یعنی:

```text
5 × 2 × 2 = 20
```

---

## 13. شیفت به راست `>>`

شیفت به راست در مبنای 2، برای اعداد صحیح مثبت، معمولاً معادل تقسیم صحیح بر توان های 2 است.

مثال:

```python
x = 20

print(x >> 1)
```

خروجی:

```text
10
```

یعنی:

```text
20 // 2 = 10
```

دو بار شیفت:

```python
print(x >> 2)
```

یعنی:

```text
20 // 4 = 5
```

---

# خلاصه عملگرها

| دسته | عملگرها |
|---|---|
| مقایسه ای | `==` `!=` `>` `<` `>=` `<=` |
| منطقی | `and` `or` `not` |
| XOR منطقی | `^` |
| Bitwise AND | `&` |
| Bitwise OR | `|` |
| Shift Left | `<<` |
| Shift Right | `>>` |
