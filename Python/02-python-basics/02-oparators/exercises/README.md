# Exercises — Operators

در این بخش تمرین های مربوط به عملگرهای مقایسه ای، منطقی و Bitwise قرار دارند.

---

## تمرین 1 — عملگرهای مقایسه ای

دو متغیر زیر را تعریف کنید:

```python
a = 10
b = 5
```

نتیجه مقایسه های زیر را با `print()` نمایش دهید:

- آیا `a` با `b` برابر است؟
- آیا `a` با `b` برابر نیست؟
- آیا `a` بزرگ تر از `b` است؟
- آیا `a` کوچک تر از `b` است؟
- آیا `a` بزرگ تر یا مساوی `b` است؟
- آیا `a` کوچک تر یا مساوی `b` است؟

---

## تمرین 2 — بررسی نوع Boolean

عبارت های زیر را اجرا کنید و نوع خروجی هرکدام را با `type()` بررسی کنید:

```python
print(type(10 > 5))
print(type(10 == 5))
print(type(10 != 5))
```

## تمرین 15 — ترکیب عملگرها

دو متغیر زیر را تعریف کنید:

```python
a = 12
b = 8
```

عبارتی بنویسید که بررسی کند:

1. آیا `a` بزرگ تر از `b` است؟
2. آیا `a` بزرگ تر از `10` و `b` کوچک تر از `10` است؟
3. آیا `a` برابر `b` است؟
4. آیا `a` با `b` برابر نیست؟
5. آیا حداقل یکی از دو شرط زیر درست است؟
   - `a < 10`
   - `b < 10`
