## تمرین 7


## تمرین 8

## تمرین 9
لیست تو در توی زیر را ایجاد کنید:

```python
data = [
    ["Apple", "Orange"],
    [4, 5, 7, 1],
    ["Carrot", "Potato"],
    ["Kiwi", "Banana", "Mango"]
]
```

سپس:

1. لیست اول را نمایش دهید.
2. عنصر اول لیست اول را نمایش دهید.
3. عنصر سوم لیست دوم را نمایش دهید.
4. عنصر دوم لیست چهارم را نمایش دهید.

---

## تمرین 10
