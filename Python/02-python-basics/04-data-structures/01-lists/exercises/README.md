# تمرین های List در Python

## تمرین 1 — ساخت لیست

یک لیست به نام `fruits` بسازید که شامل موارد زیر باشد:


## تمرین 11 — append و extend

دو لیست زیر را در نظر بگیرید:

```python
a = [1, 2, 3]
b = [4, 5, 6]
```

دو حالت زیر را جداگانه بررسی کنید:

### حالت اول
`b` را با `append()` به `a` اضافه کنید.

### حالت دوم
`b` را با `extend()` به `a` اضافه کنید.

خروجی هر دو حالت را مشاهده و تفاوت آن ها را بررسی کنید.

## تمرین 25 — تمرین نهایی List


2. کوچک ترین عدد را پیدا کند.
3. تعداد اعضا را مشخص کند.
4. تعداد تکرار عدد `2` را مشخص کند.
5. عدد `6` را با `append()` اضافه کند.
6. عدد `7` را با `insert()` در جایگاه مناسب اضافه کند.
7. لیست را به صورت صعودی مرتب کند.
8. در نهایت لیست را چاپ کند.
