# Lists در Python

## 1. List چیست؟

در برنامه نویسی همیشه با یک مقدار سر و کار نداریم. گاهی لازم است تعداد زیادی داده را در کنار هم نگهداری کنیم.

برای مثال:

- مجموعه ای از اعداد
- مجموعه ای از نام ها
- داده های یک مجموعه
- اطلاعات چندین مورد مختلف

یکی از ساختارهای داده داخلی Python برای نگهداری مجموعه ای از داده ها، **List** است.

List را با `[]` تعریف می کنیم.

```python
x = []
```

نوع متغیر:

```python
print(type(x))
```

خروجی:

```text
<class 'list'>
```

---

## 2. ساخت List با چند عضو

اعضای List با `,` از یکدیگر جدا می شوند.

```python
x = ["Apple", "Orange"]

print(x)
```

---

## 3. تعداد اعضای List

برای به دست آوردن تعداد اعضای List از `len()` استفاده می کنیم.

```python
x = []

print(len(x))
```

خروجی:

```text
0
```

مثال:

```python
x = ["Apple", "Orange"]

print(len(x))
```

خروجی:

```text
2
```

---

## 4. دسترسی به اعضای List

شماره گذاری اعضای List از **صفر** شروع می شود.

```python
x = ["Apple", "Orange"]

print(x[0])
print(x[1])
```

خروجی:

```text
Apple
Orange
```

بنابراین:

```text
x[0] → عضو اول
x[1] → عضو دوم
```

---

## 5. اندیس منفی

می توانیم از انتهای List نیز به اعضا دسترسی داشته باشیم.

```python
x = ["Apple", "Orange"]

print(x[-1])
print(x[-2])
```

خروجی:

```text
Orange
Apple
```

در اندیس گذاری منفی:

```text
-1 → آخرین عضو
-2 → عضو یکی مانده به آخر
-3 → عضو سه تا مانده به آخر
```

مثلاً اگر یک List چهار عضو داشته باشد:

```text
0   1   2   3
-4 -3  -2  -1
```

بنابراین:

```python
x[0] == x[-4]
```

---

## 6. List می تواند انواع مختلف داده داشته باشد

اعضای یک List لازم نیست هم نوع باشند.

مثلاً:

```python
data = [10, "Python", 2.5]
```

در این List:

```text
10       → عدد صحیح
"Python" → رشته
2.5      → عدد اعشاری
```

حتی یک List هم می تواند یکی از اعضای List دیگری باشد.

---

# 7. List تو در تو

یک List می تواند به عنوان عضو یک List دیگر قرار بگیرد.

```python
x = ["Apple", "Orange"]
y = ["Carrot", "Potato"]

z = [x, y]
```

در این حالت:

```text
z
├── x
│   ├── Apple
│   └── Orange
│
└── y
    ├── Carrot
    └── Potato
```

---

## 8. دسترسی به List تو در تو

برای دسترسی به اعضای Listهای داخلی، از چند `[]` استفاده می کنیم.

مثلاً:

```python
print(z[0])
```

خروجی:

```text
["Apple", "Orange"]
```

برای دسترسی به `Apple`:

```python
print(z[0][0])
```

یعنی:

```text
z[0]    → List اول
z[0][0] → عضو اول List اول
```

---

## 9. مثال دسترسی به Potato

```python
z = [
    ["Apple", "Orange"],
    ["Carrot", "Potato"]
]

print(z[1][1])
```

خروجی:

```text
Potato
```

چرا؟

```text
z[1]    → List دوم
z[1][1] → عضو دوم List دوم
```

---

## 10. Listهای چندلایه

این ساختار می تواند چندین سطح داشته باشد.

مثلاً:

```python
z = [
    ["Apple", "Orange"],
    ["Carrot", "Potato"],
    ["Kiwi", "Banana", "Mango"]
]
```

برای دسترسی به `Potato`:

```python
print(z[1][1])
```

برای دسترسی به `Mango`:

```python
print(z[2][2])
```

هر `[]` یک سطح از ساختار را مشخص می کند.

---

## 11. Listهای نامنظم

Listهای داخلی لازم نیست تعداد اعضای یکسانی داشته باشند.

مثلاً:

```python
z = [
    ["Apple", "Orange"],
    [4, 5, 7, 1],
    ["Carrot", "Potato"],
    ["Kiwi", "Banana", "Mango"]
]
```

تعداد اعضای Listهای داخلی متفاوت است.

Python این ساختار را قبول می کند.

---

## 12. Listهای چندبعدی بیشتر

یک List می تواند خودش عضو List دیگری باشد و این ساختار می تواند چندین سطح ادامه پیدا کند.

مثلاً:

```python
data = [
    [
        ["Apple", "Orange"],
        ["Carrot", "Potato"]
    ]
]
```

در چنین ساختاری برای دسترسی به اعضای عمیق تر، `[]` بیشتری استفاده می کنیم.

هرچه یک List بیشتر داخل Listهای دیگر قرار گرفته باشد، دسترسی به آن نیز به اندیس های بیشتری نیاز دارد.

> اگر ساختار داده خیلی پیچیده و شبیه ماتریس شود، استفاده از ابزارهایی مانند **NumPy** و **Pandas** می تواند مناسب تر باشد.

# 13. Slicing یا برش دادن List

گاهی به جای یک عضو، می خواهیم تعدادی از اعضای List را انتخاب کنیم.

برای این کار از `:` استفاده می کنیم.

ساختار:

```python
list[start:stop]
```

نکته مهم:

**عضو `stop` در نتیجه قرار نمی گیرد.**

مثلاً:

```python
numbers = list(range(101))

print(numbers[0:4])
```

خروجی:

```text
[0, 1, 2, 3]
```

یعنی:

```text
0
1
2
3
```

انتخاب شده اند و `4` شامل نتیجه نیست.

# 14. ساخت List از ۰ تا ۱۰۰

می توانیم با `range()` و `list()` یک List از ۰ تا ۱۰۰ بسازیم.

```python
numbers = list(range(101))

print(numbers)
```

چون `range(101)` قبل از ۱۰۱ متوقف می شود، آخرین عدد List برابر با `100` خواهد بود.

```text

```

# 17. Step در Slicing

ساختار کامل Slicing:

```python
list[start:stop:step]
```

قسمت `step` مشخص می کند چند خانه چند خانه جلو برویم.

مثلاً:

```python
numbers = list(range(10))

print(numbers[0:10:2])
```

خروجی:

```text
[0, 2, 4, 6, 8]
```

یعنی از صفر شروع شده و دو تا دو تا جلو رفته است.

مثال دیگر:

```python
print(numbers[::3])
```

یعنی از ابتدا تا انتها، سه تا سه تا حرکت کن.

بنابراین اگر داده ها واقعاً عدد هستند، بهتر است آنها را به نوع عددی تبدیل کنیم.

```python
numbers = [1, 94, 93, 1000]

print(max(numbers))
```

```text

```

# 22. `in` برای بررسی وجود یک عضو

با `in` می توانیم بررسی کنیم یک مقدار در List وجود دارد یا خیر.

```python
names = ["Ali", "Sara", "Reza"]

print("Ali" in names)
```

خروجی:

```text
True
```

اما:

```python
print("Javad" in names)
```

خروجی:

```text
False
```

این ویژگی در شرط ها نیز کاربرد زیادی دارد.

مثلاً:

```python
if "Ali" in names:
    print("Ali is in the list")
```

# 23. ترکیب Listها با `+`

عملگر `+` برای Listها باعث ترکیب اعضای دو List می شود.

```python
list1 = [1, 2, 3]

result = list1 + list2

print(result)
```

خروجی:


# 26. `append()` برای اضافه کردن یک List

اگر یک List را با `append()` اضافه کنیم، کل List به عنوان **یک عضو** اضافه می شود.

```python
a = [1, 2, 3]

print(a)
```

خروجی:

```text

```

# 27. `extend()`

اگر بخواهیم اعضای یک List را به انتهای List دیگر اضافه کنیم، می توانیم از `extend()` استفاده کنیم.

```python
a = [1, 2, 3]
b = [4, 5, 6]

a.extend(b)

print(a)
```

خروجی:

```text
[1, 2, 3, 4, 5, 6]
```

تفاوت:

```text
append() → کل List را یک عضو در نظر می گیرد.

extend() → اعضای List را جداگانه اضافه می کند.
```

# 28. `index()`

با `index()` می توانیم اولین موقعیتی را که یک مقدار در List قرار دارد پیدا کنیم.

```python
numbers = [1, 7, 5, 1, 9]

print(numbers.index(1))
```

خروجی:

```text
0
```

چون اولین `1` در اندیس صفر قرار دارد.

اگر اولین مورد حذف یا تغییر داده شود:

```python
numbers[0] = 10

print(numbers.index(1))
```

حالا اولین `1` در اندیس `3` قرار دارد.

# 41. کپی کردن List

یکی از نکات مهم List، نحوه کپی کردن آن است.

اگر بنویسیم:

```python
a = [2, 1, 4, 3]

b = a
```

این به معنی ساخت یک List کاملاً جدید نیست.

`a` و `b` به همان List اشاره می کنند.

می توانیم با `id()` این موضوع را بررسی کنیم:

```python
print(id(a))
print(id(b))
```

اگر دو مقدار یکسان باشند، یعنی هر دو به یک شیء در حافظه اشاره می کنند.

---

# 42. مشکل کپی با `=`

مثلاً:

```python

b = a

b[0] = 100

print(a)
print(b)
```

خروجی:

```text
[100, 1, 4, 3]
[100, 1, 4, 3]
```

تغییر `b` باعث تغییر `a` نیز شد.

دلیل آن این است که `b = a` یک کپی مستقل ایجاد نکرده است.

# 43. کپی مستقل با `copy()`

## نکات کلیدی List

- List با `[]` ساخته می شود.
- اندیس ها از `0` شروع می شوند.
- اندیس منفی از انتهای List شروع می شود.
- با `len()` تعداد اعضا را به دست می آوریم.
- با `:` می توانیم Slicing انجام دهیم.
- با `step` می توانیم مشخص کنیم چند خانه چند خانه جلو برویم.
- List می تواند اعضایی با نوع های مختلف داشته باشد.
- یک List می تواند شامل Listهای دیگر باشد.
- List در Python **قابل تغییر (Mutable)** است.
- `append()` یک عضو را به انتهای List اضافه می کند.
- `extend()` اعضای یک List دیگر را اضافه می کند.
- `insert()` یک عضو را در موقعیت مشخص قرار می دهد.
- `pop()` یک عضو را حذف و مقدار آن را برمی گرداند.
- `reverse()` ترتیب اعضا را معکوس می کند.
- `sort()` اعضا را مرتب می کند.
- `copy()` برای ساخت یک کپی مستقل ساده استفاده می شود.
