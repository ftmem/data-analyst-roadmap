# Lists

لیست یکی از ساختارهای داده ی اصلی و پرکاربرد در Python است.

وقتی به جای یک مقدار، نیاز داشته باشیم چندین مقدار را در یک متغیر نگهداری کنیم، می توانیم از `list` استفاده کنیم.

برای مثال، ممکن است بخواهیم چند عدد، چند نام، چند اندازه گیری یا مجموعه ای از داده ها را در کنار هم ذخیره کنیم.

---

## 1. ساخت یک لیست

برای ساخت لیست از `[]` یا همان Square Brackets استفاده می کنیم.

یک لیست خالی:

```python
x = []
```

برای بررسی نوع آن:

```python
print(type(x))
```

خروجی:

```text
<class 'list'>
```

---

## 2. قرار دادن چند عضو در لیست

اعضای یک لیست را با `,` از یکدیگر جدا می کنیم.

مثلاً:

```python
x = ["Apple", "Orange"]
```

در این مثال لیست `x` دو عضو دارد:

```text
Apple
Orange
```

برای به دست آوردن تعداد اعضای لیست می توانیم از `len()` استفاده کنیم:

```python
print(len(x))
```

خروجی:

```text
2
```

---

## 3. دسترسی به اعضای لیست

شماره گذاری اعضای لیست از **صفر** شروع می شود.

مثلاً:

```python
x = ["Apple", "Orange"]
```

شماره ی اعضا:

```text
Apple   → 0
Orange  → 1
```

برای دسترسی به یک عضو، شماره ی آن را داخل `[]` قرار می دهیم.

```python
print(x[0])
```

خروجی:

```text
Apple
```

و:

```python
print(x[1])
```

خروجی:

```text
Orange
```

---

## 4. Index

شماره ای که برای دسترسی به عضو لیست استفاده می کنیم، **Index** نام دارد.

Index از صفر شروع می شود.

برای یک لیست چهار عضوی:

```python
x = ["A", "B", "C", "D"]
```

Indexها به این شکل هستند:

```text
A → 0
B → 1
C → 2
D → 3
```

بنابراین آخرین Index همیشه برابر است با:

```text
len(list) - 1
```

---

## 5. دسترسی از انتهای لیست

در Python می توانیم اعضای لیست را از انتها نیز شماره گذاری کنیم.

در این حالت آخرین عضو Index برابر با `-1` دارد.

مثلاً:

```python
x = ["Apple", "Orange"]
```

شماره گذاری از انتها:

```text
Orange → -1
Apple  → -2
```

بنابراین:

```python
print(x[-1])
```

خروجی:

```text
Orange
```

و:

```python
print(x[-2])
```

خروجی:

```text
Apple
```

---

## 6. مقایسه Index مثبت و منفی

برای لیست:

```python
x = ["Apple", "Orange"]
```

این دو عبارت یک نتیجه دارند:

```python
print(x[0])
print(x[-2])
```

هر دو خروجی:

```text
Apple
```

و این دو نیز یک نتیجه دارند:

```python
print(x[1])
print(x[-1])
```

خروجی:

```text
Orange
```

---

## 7. لیست های مختلف

اعضای یک لیست لزوماً نباید از یک نوع داده باشند.

مثلاً یک لیست عددی:

```python
numbers = [4, 5, 7, 1]
```

یک لیست رشته ای:

```python
fruits = ["Apple", "Orange"]
```

و حتی می توانیم انواع مختلف داده را در یک لیست قرار دهیم:

```python
data = [10, "Python", 2.5]
```

در Python انعطاف بیشتری نسبت به آرایه های سنتی زبان هایی مثل C داریم.

---

## 8. قرار دادن یک لیست داخل لیست دیگر

یک لیست می تواند خودش یکی از اعضای یک لیست دیگر باشد.

مثلاً:

```python
x = ["Apple", "Orange"]
y = ["Carrot", "Potato"]

z = [x, y]
```

در اینجا:

```text
z
├── x
│   ├── Apple
│   └── Orange
│
└── y
    ├── Carrot
    └── Potato
```

پس `z` یک لیست است که اعضای آن خودشان لیست هستند.

---

## 9. لیست چندبعدی

وقتی یک لیست شامل لیست های دیگری باشد، می توانیم آن را به صورت یک ساختار چندبعدی در نظر بگیریم.

مثلاً:

```python
x = ["Apple", "Orange"]
y = ["Carrot", "Potato"]

z = [x, y]
```

برای دسترسی به اولین لیست:

```python
print(z[0])
```

خروجی:

```text
['Apple', 'Orange']
```

برای دسترسی به اولین عضو اولین لیست:

```python
print(z[0][0])
```

خروجی:

```text
Apple
```

---

## 10. چند مرحله ورود به لیست

هر `[]` یک مرحله ما را به داخل ساختار می برد.

مثلاً:

```python
z[0]
```

یعنی:

> عضو اول `z`

و:

```python
z[0][0]
```

یعنی:

> عضو اول `z` → عضو اول آن لیست

مثال:

```python
z = [
    ["Apple", "Orange"],
    ["Carrot", "Potato"]
]

print(z[0][0])
```

خروجی:

```text
Apple
```

برای دسترسی به `Potato`:

```python
print(z[1][1])
```

خروجی:

```text
Potato
```

---

## 11. ساختارهای چندلایه

لیست ها می توانند چندین سطح داشته باشند.

مثلاً:

```python
z = [
    ["Apple", "Orange"],
    [4, 5, 7, 1],
    ["Carrot", "Potato"],
    ["Kiwi", "Banana", "Mango"]
]
```

در این مثال، `z` چهار عضو دارد و هر عضو خودش یک لیست است.

نکته مهم این است که تعداد اعضای لیست های داخلی الزاماً برابر نیست.

مثلاً:

```text
لیست اول  → 2 عضو
لیست دوم  → 4 عضو
لیست سوم  → 2 عضو
لیست چهارم → 3 عضو
```

---

## 12. انعطاف پذیری List

یکی از ویژگی های مهم `list` در Python انعطاف پذیری آن است.

اعضای یک لیست می توانند از انواع مختلفی باشند:

```python
data = [
    ["Apple", "Orange"],
    [4, 5, 7, 1],
    "Python",
    10
]
```

در این مثال اعضای `data` انواع مختلفی دارند.

---

## 13. نکته مهم درباره لیست های چندبعدی

در هنگام کار با لیست های چندبعدی باید بدانیم هر عضو خودش چه نوعی دارد و چند عضو دارد.

برای مثال:

```python
z = [
    ["Apple", "Orange"],
    [4, 5, 7, 1]
]
```

این عبارت صحیح است:

```python
print(z[0][1])
```

چون عضو اول `z` خودش یک لیست دو عضوی است.

اما اگر بخواهیم به عضوی دسترسی پیدا کنیم که وجود ندارد، با خطا مواجه می شویم.

بنابراین هنگام کار با لیست های چندلایه باید به Index هر سطح توجه کنیم.

---

## 14. مثال کامل

```python
x = ["Apple", "Orange"]
y = ["Carrot", "Potato"]

z = [x, y]

print(z)
print(z[0])
print(z[0][0])
print(z[1])
print(z[1][1])
```

خروجی:

```text
[['Apple', 'Orange'], ['Carrot', 'Potato']]
['Apple', 'Orange']
Apple
['Carrot', 'Potato']
Potato
```

---
## 15. دسترسی به عناصر در لیست های تو در تو

وقتی یک لیست شامل لیست های دیگری باشد، برای دسترسی به عناصر داخلی، به ازای هر سطح یک جفت `[]` استفاده می کنیم.

مثلاً:

```python
z = [
    ["Apple", "Orange"],
    [4, 5, 7, 1],
    ["Carrot", "Potato"],
    ["Kiwi", "Banana", "Mango"]
]
```

برای دسترسی به **عنصر دوم لیست سوم** می نویسیم:

```python
print(z[2][1])
```

خروجی:

```text
Potato
```

دلیل:

```text
z[2]     → لیست سوم
z[2][1]  → عنصر دوم لیست سوم
```

---

## 16. دسترسی به عمق های بیشتر

این روش فقط برای لیست دوبعدی نیست.

اگر لیست ها چندین سطح داشته باشند، با اضافه کردن `[]` می توانیم وارد سطح بعدی شویم.

مثلاً:

```python
z[a][b][c]
```

هر `[]` یک مرحله ما را به داخل ساختار می برد.

بنابراین اگر یک لیست شامل لیست دیگری باشد و آن لیست هم شامل یک لیست دیگر باشد، می توانیم با همین روش به عناصر داخلی دسترسی پیدا کنیم.

---

## 17. چند مثال

### لیست اول، عضو دوم

```python
print(z[0][1])
```

خروجی:

```text
Orange
```

### لیست دوم، عضو چهارم

```python
print(z[1][3])
```

خروجی:

```text
1
```

### لیست چهارم، عضو سوم

```python
print(z[3][2])
```

خروجی:

```text
Mango
```

---

## 18. نکته مهم درباره لیست های چندبعدی

Python اجازه می دهد لیست ها را به صورت چندلایه و تو در تو ایجاد کنیم.

اما اگر ساختار داده حالت کاملاً ماتریسی یا چندبعدی داشته باشد، استفاده زیاد از لیست های تو در تو می تواند مدیریت داده ها را سخت تر کند.

برای کار با داده های چندبعدی و محاسبات داده ای، در ادامه با کتابخانه هایی مانند `NumPy` و `Pandas` آشنا خواهیم شد.

---

## جمع بندی تکمیلی

در لیست های تو در تو:

- هر `[]` یک سطح از لیست را مشخص می کند.
- Index از `0` شروع می شود.
- برای دسترسی به سطح بعدی، یک `[]` دیگر اضافه می کنیم.
- `z[2][1]` یعنی عنصر دوم لیست سوم.
- می توان لیست هایی با چندین سطح ایجاد کرد.
- باید هنگام دسترسی به عناصر، Index هر سطح را به درستی مشخص کنیم.


## جمع بندی

در این بخش با مفهوم `List` آشنا شدیم.

مهم ترین نکات:

- لیست برای نگهداری چند مقدار استفاده می شود.
- لیست با `[]` ساخته می شود.
- اعضای لیست با `,` از هم جدا می شوند.
- Index از `0` شروع می شود.
- آخرین عضو با `-1` قابل دسترسی است.
- `len()` تعداد اعضای لیست را مشخص می کند.
- اعضای لیست می توانند از انواع مختلف داده باشند.
- یک لیست می تواند شامل لیست دیگری باشد.
- با استفاده از چند `[]` می توان به سطوح مختلف یک لیست چندلایه دسترسی پیدا کرد.
- لیست های داخلی لازم نیست تعداد اعضای یکسانی داشته باشند.
