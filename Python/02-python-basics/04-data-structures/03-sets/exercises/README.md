# 📝 تمرین های Set در پایتون

## 🎯 هدف

در این تمرین ها با ساختار داده ی `Set` و عملیات مختلف آن تمرین می کنیم:

- ساخت Set
- حذف اعضای تکراری
- `add()`
- `union()`
- `intersection()`
- `difference()`
- `symmetric_difference()`
- `isdisjoint()`
- `issubset()`
- `issuperset()`
- `remove()`
- `pop()`
- `clear()`

### تمرین 25 — چالش نهایی ⭐

دو لیست زیر را در نظر بگیرید:

```python
list1 = [1, 2, 3, 4, 5, 5, 5]
list2 = [4, 5, 6, 7, 7, 8]
```

آن ها را به Set تبدیل کنید و سپس موارد زیر را به دست آورید:

1. تمام اعضای موجود در هر دو مجموعه
2. اعضای مشترک دو مجموعه
3. اعضایی که فقط در `list1` هستند
4. اعضایی که فقط در `list2` هستند
5. اعضایی که فقط در یکی از دو مجموعه وجود دارند
6. بررسی کنید آیا دو مجموعه `disjoint` هستند یا خیر
