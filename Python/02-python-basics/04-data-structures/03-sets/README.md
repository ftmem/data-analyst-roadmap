# Set در Python

## Set چیست؟

`Set` یکی دیگر از ساختارهای داده در Python است.

Set برای نگهداری مجموعه ای از **اعضای منحصر به فرد** استفاده می شود.

تفاوت مهم Set با List این است که در Set اعضای تکراری نگهداری نمی شوند.

مثلاً در List می توانیم داشته باشیم:

```python
numbers = [1, 2, 2, 3, 3]
```

اما در Set اعضای تکراری حذف می شوند.

Set بیشتر برای کارهایی مانند عملیات مجموعه های ریاضی کاربرد دارد؛ برای مثال:

- اجتماع
- اشتراک
- تفاضل
- تفاضل متقارن
- بررسی زیرمجموعه بودن
- بررسی مستقل بودن مجموعه ها

---

# ساخت Set

برای ساخت یک Set می توانیم از `{}` و اعضای مجموعه استفاده کنیم:

```python
numbers = {1, 2, 3}
```

اگر آن را چاپ کنیم:

```python
print(numbers)
```

نوع آن:

```python
print(type(numbers))
```

خروجی:

```text
<class 'set'>
```

---

# تبدیل List به Set

با استفاده از `set()` می توانیم یک List را به Set تبدیل کنیم.

مثلاً:

```python
numbers = [1, 1, 2, 2, 3, 3]

numbers_set = set(numbers)

print(numbers_set)
```

خروجی مجموعه شامل اعضای تکراری نیست:

```text
{1, 2, 3}
```

بنابراین یکی از کاربردهای Set این است که بتوانیم اعضای تکراری یک List را حذف کنیم.

---

# تعریف دو Set

دو مجموعه زیر را در نظر بگیرید:

```python
set1 = {1, 2, 3}

set2 = {2, 3, 4, 5}
```

دو عضو بین این مجموعه ها مشترک هستند:

```text
2
3
```

و هر مجموعه نیز اعضایی دارد که در مجموعه دیگر وجود ندارند.

---

# اجتماع دو Set

برای گرفتن اجتماع دو مجموعه از `union()` استفاده می کنیم:

```python
set1.union(set2)
```

مثلاً:

```python
set1 = {1, 2, 3}
set2 = {2, 3, 4, 5}

result = set1.union(set2)

print(result)
```

خروجی:

```text
{1, 2, 3, 4, 5}
```

در اجتماع، تمام اعضای دو مجموعه قرار می گیرند؛ اما اعضای مشترک فقط یک بار نمایش داده می شوند.

---

# اضافه کردن عضو با add()

با استفاده از `add()` می توانیم یک عضو به Set اضافه کنیم.

مثلاً:

```python
set1 = {1, 2, 3}

set1.add(4)

print(set1)
```

خروجی:

```text
{1, 2, 3, 4}
```

اگر عضوی که اضافه می کنیم از قبل در Set وجود داشته باشد، عضو تکراری ایجاد نمی شود.

مثلاً:

```python
set1.add(3)
```

چون `3` قبلاً وجود دارد، Set همچنان فقط یک `3` خواهد داشت.

---

# اشتراک دو Set

برای گرفتن اشتراک دو مجموعه از `intersection()` استفاده می کنیم.

مثلاً:

```python
set1 = {1, 2, 3}
set2 = {2, 3, 4, 5}

result = set1.intersection(set2)

print(result)
```

خروجی:

```text
{2, 3}
```

اشتراک یعنی اعضایی که **در هر دو مجموعه وجود دارند**.

---

# تفاضل دو Set

با `difference()` می توانیم تفاضل دو مجموعه را به دست آوریم.

مثلاً:

```python
set1 = {1, 2, 3}
set2 = {2, 3, 4, 5}

result = set1.difference(set2)

print(result)
```

خروجی:

```text
{1}
```

یعنی اعضایی که در `set1` وجود دارند اما در `set2` وجود ندارند.

---

## جهت تفاضل مهم است

اگر برعکس عمل کنیم:

```python
result = set2.difference(set1)

print(result)
```

خروجی:

```text
{4, 5}
```

پس:

```python
set1.difference(set2)
```

با:

```python
set2.difference(set1)
```

یکسان نیست.

---

# تفاضل متقارن

برای گرفتن **تفاضل متقارن** از `symmetric_difference()` استفاده می کنیم.

مثلاً:

```python
set1 = {1, 2, 3}
set2 = {2, 3, 4, 5}

result = set1.symmetric_difference(set2)

print(result)
```

خروجی:

```text
{1, 4, 5}
```

در تفاضل متقارن، اعضایی را می گیریم که فقط در یکی از دو مجموعه وجود دارند.

اعضای مشترک حذف می شوند.

---

# بررسی مستقل بودن دو Set

برای بررسی اینکه دو مجموعه هیچ عضو مشترکی ندارند یا نه، از:

```python
isdisjoint()
```

استفاده می کنیم.

مثلاً:

```python
set1 = {1, 2, 3}
set2 = {2, 3, 4, 5}

print(set1.isdisjoint(set2))
```

خروجی:

```text
False
```

چون دو مجموعه عضو مشترک دارند.

اگر دو مجموعه هیچ عضو مشترکی نداشته باشند، نتیجه `True` خواهد بود.

---

# بررسی زیرمجموعه بودن

با `issubset()` می توان بررسی کرد که آیا یک مجموعه زیرمجموعه مجموعه دیگر است یا خیر.

مثلاً:

```python
set1 = {1, 2}
set2 = {1, 2, 3, 4}

print(set1.issubset(set2))
```

خروجی:

```text
True
```

چون تمام اعضای `set1` در `set2` وجود دارند.

---

# بررسی مجموعه بالاسری با issuperset()

با `issuperset()` می توان بررسی کرد که آیا یک مجموعه شامل تمام اعضای مجموعه دیگر است یا خیر.

مثلاً:

```python
set1 = {1, 2, 3, 4}
set2 = {1, 2}

print(set1.issuperset(set2))
```

خروجی:

```text
True
```

چون تمام اعضای `set2` در `set1` وجود دارند.

---

# pop()

با `pop()` می توان یک عضو را از Set حذف کرد.

مثلاً:

```python
set1 = {1, 2, 3, 4}

result = set1.pop()

print(result)
print(set1)
```

نکته مهم:

**Set ترتیب مشخصی برای اعضا ندارد.**

بنابراین نباید فرض کنیم `pop()` حتماً کوچک ترین، بزرگ ترین یا اولین عددی را که هنگام نمایش می بینیم حذف می کند.

`pop()` یک عضو را حذف و همان عضو را برمی گرداند.

---

# remove()

با `remove()` می توانیم یک عضو مشخص را از Set حذف کنیم.

مثلاً:

```python
set1 = {1, 2, 3, 4}

set1.remove(2)

print(set1)
```

خروجی:

```text
{1, 3, 4}
```

در این حالت مشخص کرده ایم که دقیقاً عضو `2` حذف شود.

---

# clear()

با `clear()` تمام اعضای Set حذف می شوند.

مثلاً:

```python
set1 = {1, 2, 3, 4}

set1.clear()

print(set1)
```

خروجی:

```text
set()
```

یعنی مجموعه خالی شده است.

---

# خلاصه عملیات مهم Set

| عملیات | کاربرد |
|---|---|
| `set()` | تبدیل داده به Set |
| `union()` | اجتماع دو مجموعه |
| `add()` | اضافه کردن یک عضو |
| `intersection()` | اشتراک دو مجموعه |
| `difference()` | تفاضل دو مجموعه |
| `symmetric_difference()` | تفاضل متقارن |
| `isdisjoint()` | بررسی نداشتن عضو مشترک |
| `issubset()` | بررسی زیرمجموعه بودن |
| `issuperset()` | بررسی مجموعه بالاسری |
| `pop()` | حذف و برگرداندن یک عضو |
| `remove()` | حذف یک عضو مشخص |
| `clear()` | حذف تمام اعضا |

---

# تفاوت Set و List

مهم ترین تفاوتی که فعلاً باید به خاطر داشته باشیم:

```text
List → می تواند اعضای تکراری داشته باشد

Set → اعضای تکراری ندارد
```

مثلاً:

```python
numbers = [1, 2, 2, 3, 3]
```

اما:

```python
numbers = {1, 2, 2, 3, 3}

print(numbers)
```

نتیجه:

```text
{1, 2, 3}
```

بنابراین Set برای زمانی مناسب است که **منحصر به فرد بودن اعضا** و انجام عملیات مجموعه ای اهمیت داشته باشد.
