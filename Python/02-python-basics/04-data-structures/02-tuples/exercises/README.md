
1. `"Python"` را چاپ کند.
2. عدد `10` را چاپ کند.
3. عدد `50` را از Tuple داخلی چاپ کند.
4. Tuple داخلی را چاپ کند.
5. نوع `data` را چاپ کند.
6. نوع Tuple داخلی را چاپ کند.
