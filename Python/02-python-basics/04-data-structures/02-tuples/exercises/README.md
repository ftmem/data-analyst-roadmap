# تمرین های Tuple در Python

## تمرین 1 — ساخت Tuple

یک Tuple به نام `numbers` بسازید که شامل اعداد زیر باشد:

```python
10, 20, 30, 40, 50
```

سپس نوع متغیر را چاپ کنید.

---

## تمرین 2 — دسترسی به اعضای Tuple

Tuple زیر را در نظر بگیرید:

```python
names = ("Ali", "Sara", "Reza", "Mina")
```

کدهایی بنویسید که:

1. اولین عضو را چاپ کند.
2. سومین عضو را چاپ کند.
3. آخرین عضو را با اندیس منفی چاپ کند.
4. دومین عضو از آخر را چاپ کند.

---

## تمرین 3 — Tuple یک عضوی


نوع هر دو متغیر را چاپ کنید و تفاوت آن ها را مشاهده کنید.

## تمرین 7 — Slicing

Tuple زیر را در نظر بگیرید:

```python

```

کدهایی بنویسید که:

1. اعضای اندیس 0 تا 3 را چاپ کند.
2. از اندیس 4 تا انتها را چاپ کند.
3. اعضای یکی درمیان را چاپ کند.

## تمرین 9 — Tuple تو در تو

4. عدد `40` را چاپ کنید.

## تمرین 11 — index()

## تمرین 12 — Tuple Unpacking

Tuple زیر را در نظر بگیرید:

```python

```

آن را در سه متغیر زیر قرار دهید:

```text

b
c
```

سپس مقدار هر سه متغیر را چاپ کنید.

## تمرین 18 — تمرین نهایی Tuple

برنامه ای بنویسید که Tuple زیر را:

```python
data = ("Python", 10, 20, "Data", 30)
```

به صورت زیر بررسی کند:

1. نوع Tuple را چاپ کند.
2. تعداد اعضا را مشخص کند.
3. اولین عضو را چاپ کند.
4. آخرین عضو را چاپ کند.
5. عضو `"Data"` را پیدا کند.
6. Tuple را از اندیس 1 تا 4 برش دهد.
7. یک Tuple جدید بر اساس Tuple اصلی ایجاد کند.
