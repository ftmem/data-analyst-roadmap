# Tuple در Python

## Tuple چیست؟

`Tuple` یکی دیگر از ساختارهای داده در Python است.

Tuple برای نگهداری چند مقدار به صورت **ترتیب دار (Ordered)** استفاده می شود.

یک Tuple می تواند چندین عضو داشته باشد و اعضای آن می توانند از نوع های مختلف باشند.

مثلاً:

```python
t = (1, 2, 3)
```

یا:

```python
t = ("Apple", "Orange", 10)
```

در یک Tuple می توانیم هم زمان رشته، عدد و انواع دیگر داده ها را داشته باشیم.

---

# ساخت Tuple

برای ساخت Tuple معمولاً از پرانتز `()` استفاده می کنیم:

```python
t = (1, 2, 3)
```

می توانیم رشته ها و انواع مختلف داده را نیز در آن قرار دهیم:

```python
t = ("Ali", "Sara", 25)
```

نوع متغیر:

```python
print(type(t))
```

خروجی:

```text
<class 'tuple'>
```

---

# تفاوت اصلی Tuple و List

مهم ترین تفاوت Tuple با List این است که **اعضای Tuple بعد از ساخته شدن قابل تغییر نیستند.**

مثلاً در List می توانیم بنویسیم:

```python
numbers = [1, 2, 3]

numbers[0] = 10

print(numbers)
```

اما در Tuple:

```python
numbers = (1, 2, 3)

numbers[0] = 10
```

این کار امکان پذیر نیست.

Tuple یک ساختار **Immutable** است.

یعنی بعد از ایجاد Tuple نمی توانیم مستقیماً اعضای آن را تغییر دهیم.

---

# Tuple و تابع divmod()

در Python بعضی توابع می توانند یک Tuple برگردانند.

مثلاً تابع `divmod()`:

```python
result = divmod(10, 3)

print(result)
```

خروجی:

```text
(3, 1)
```

می توانیم نوع خروجی را بررسی کنیم:

```python
print(type(result))
```

خروجی:

```text
<class 'tuple'>
```

پس خروجی `divmod()` یک Tuple است.

---

# Tuple یک عضوی

برای ساخت Tuple که فقط **یک عضو** دارد، باید بعد از آن عضو یک کاما قرار دهیم.

درست:

```python
x = (1,)
```

نوع آن:

```python
print(type(x))
```

خروجی:

```text
<class 'tuple'>
```

اما اگر بنویسیم:

```python
x = (1)
```

این Tuple نیست.

در این حالت:

```python
print(type(x))
```

خروجی:

```text
<class 'int'>
```

چون پرانتز به تنهایی Tuple ایجاد نمی کند؛ **کاما** است که Tuple یک عضوی را ایجاد می کند.

---

# تکرار Tuple

همان طور که می توانیم یک رشته را چند بار تکرار کنیم:

```python
text = "Hi"

print(text * 3)
```

خروجی:

```text
HiHiHi
```

می توانیم Tuple را نیز تکرار کنیم.

مثلاً:

```python
x = (1,)

print(x * 3)
```

خروجی:

```text
(1, 1, 1)
```

بنابراین عملگر `*` در اینجا باعث تکرار اعضای Tuple می شود.

---

# تبدیل List به Tuple

با استفاده از `tuple()` می توانیم یک List را به Tuple تبدیل کنیم.

مثلاً:

```python
numbers = [1, 2, 3, 4]

t = tuple(numbers)

print(t)
```

خروجی:

```text
(1, 2, 3, 4)
```

نوع آن:

```python
print(type(t))
```

خروجی:

```text
<class 'tuple'>
```

---

# تبدیل String به Tuple

می توانیم یک String را نیز با `tuple()` به Tuple تبدیل کنیم.

مثلاً:

```python
text = "Hello"

t = tuple(text)

print(t)
```

خروجی:

```text
('H', 'e', 'l', 'l', 'o')
```

در این حالت هر کاراکتر String به یک عضو Tuple تبدیل می شود.

---

# دسترسی به اعضای Tuple

دسترسی به اعضای Tuple دقیقاً مانند List با استفاده از `[]` انجام می شود.

مثلاً:

```python
t = ("Ali", "Sara", "Reza")

print(t[0])
print(t[1])
print(t[2])
```

خروجی:

```text
Ali
Sara
Reza
```

اندیس گذاری از `0` شروع می شود.

---

# اندیس منفی

Tuple مانند List از اندیس منفی نیز پشتیبانی می کند.

```python
t = ("Ali", "Sara", "Reza")

print(t[-1])
```

خروجی:

```text
Reza
```

`-1` آخرین عضو را نشان می دهد.

---

# Slicing در Tuple

می توانیم روی Tuple نیز مانند List عملیات Slicing انجام دهیم.

مثلاً:

```python
numbers = (0, 1, 2, 3, 4, 5)

print(numbers[1:4])
```

خروجی:

```text
(1, 2, 3)
```

توجه کنید که نتیجه Slicing همچنان یک Tuple است.

---

# Tuple Unpacking

یکی از کاربردهای مهم Tuple، **Unpacking** است.

فرض کنید یک تابع چند مقدار برگرداند:

```python
def get_data():
    return 10, 20, 30
```

می توانیم خروجی آن را مستقیماً در چند متغیر قرار دهیم:

```python
a, b, c = get_data()

print(a)
print(b)
print(c)
```

خروجی:

```text
10
20
30
```

یعنی:

```text
a ← مقدار اول
b ← مقدار دوم
c ← مقدار سوم
```

در واقع مقادیر برگشتی به صورت یک Tuple در نظر گرفته می شوند و سپس بین متغیرها تقسیم می شوند.

---

# Nested Tuple

یک Tuple می تواند Tuple دیگری را نیز به عنوان یکی از اعضای خودش داشته باشد.

مثلاً:

```python
t = (1, (2, 3, 4))
```

در اینجا Tuple اصلی دو عضو دارد:

```text
1
(2, 3, 4)
```

برای دسترسی به عضو اول:

```python
print(t[0])
```

خروجی:

```text
1
```

برای دسترسی به Tuple داخلی:

```python
print(t[1])
```

خروجی:

```text
(2, 3, 4)
```

و برای دسترسی به یکی از اعضای Tuple داخلی:

```python
print(t[1][0])
```

خروجی:

```text
2
```

---

# count()

Tuple مانند List دارای متد `count()` است.

این متد تعداد تکرار یک مقدار را مشخص می کند.

مثلاً:

```python
numbers = (1, 2, 2, 3, 2, 4)

print(numbers.count(2))
```

خروجی:

```text
3
```

---

# index()

می توانیم با `index()` محل اولین وقوع یک مقدار را پیدا کنیم.

مثلاً:

```python
numbers = (10, 20, 30, 20, 40)

print(numbers.index(20))
```

خروجی:

```text
1
```

چون اولین `20` در اندیس `1` قرار دارد.

---

# عدم امکان تغییر مستقیم Tuple

فرض کنید:

```python
numbers = (10, 20, 30)
```

نمی توانیم بنویسیم:

```python
numbers[0] = 100
```

چون Tuple قابل تغییر نیست.

اگر نیاز داشته باشیم نسخه ای متفاوت از Tuple داشته باشیم، باید یک Tuple جدید ایجاد کنیم.

مثلاً:

```python
numbers = (10, 20, 30)

new_numbers = (100,) + numbers[1:]

print(new_numbers)
```

خروجی:

```text
(100, 20, 30)
```

در اینجا Tuple قبلی را تغییر نداده ایم؛ بلکه یک Tuple جدید ساخته ایم.

## نکته مهم

تفاوت اصلی که فعلاً باید بین List و Tuple به خاطر داشته باشیم:

```text
List  → قابل تغییر
Tuple → غیرقابل تغییر
```

مثلاً:

```python
my_list = [1, 2, 3]
my_list[0] = 10
```

مجاز است.

اما:

```python
my_tuple = (1, 2, 3)
my_tuple[0] = 10
```

مجاز نیست.
