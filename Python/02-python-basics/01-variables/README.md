# Variables

## متغیر چیست؟

متغیر یک نام برای نگهداری یک مقدار در برنامه است.

در پایتون هنگام تعریف متغیر، لازم نیست نوع متغیر را به صورت جداگانه مشخص کنیم. پایتون بر اساس مقداری که به متغیر می دهیم، نوع آن را تشخیص می دهد.

مثال:

```python
x = 2
y = 5
```

در این مثال:

- `x` یک متغیر است و مقدار آن `2` است.
- `y` یک متغیر است و مقدار آن `5` است.

می توانیم از متغیرها در محاسبات استفاده کنیم:

```python
x = 2
y = 5

result = x + y
```

در اینجا `result` مقدار `7` را نگهداری می کند.

---

## نام گذاری متغیرها

برای نام گذاری متغیرها باید چند قانون را رعایت کنیم:

- نام متغیر نمی تواند با عدد شروع شود.
- می توان از حروف، اعداد و `_` استفاده کرد.
- حروف بزرگ و کوچک با یکدیگر متفاوت هستند.
- نمی توان از کلمات رزروشده پایتون به عنوان نام متغیر استفاده کرد.

مثال های درست:

```python
name = "Roya"
age = 28
user_name = "Roya"
number1 = 10
```

مثال های نادرست:

```python
1name = "Roya"
user-name = "Roya"
```

همچنین کلمات رزروشده مانند `for` و `def` را نمی توان به عنوان نام متغیر استفاده کرد.

## انواع داده

پایتون می تواند نوع داده ی یک متغیر را تشخیص دهد.

### Integer

برای اعداد صحیح استفاده می شود.

```python
x = 2
y = 5
```

### String

برای نگهداری متن استفاده می شود.

رشته ها را می توان با `' '` یا `" "` تعریف کرد.

```python
name = "Roya"
message = 'Hello'
```

---

## دستور print()

برای نمایش مقدار متغیر یا نتیجه ی یک عبارت از `print()` استفاده می کنیم.

```python
x = 2

print(x)
```

خروجی:

```text
2
```

می توان چند مقدار را همزمان چاپ کرد:

```python
x = 2
y = 5

print(x, y)
```

خروجی:

```text
2 5
```

به صورت پیش فرض، `print()` بین چند مقدار یک فاصله قرار می دهد و بعد از چاپ به خط بعد می رود.

همچنین می توانیم مستقیماً یک محاسبه را داخل `print()` انجام دهیم:

```python
x = 5

print(x + 1)
```

خروجی:

```text
6
```

---

## دستور type()

برای بررسی نوع یک متغیر می توانیم از `type()` استفاده کنیم.

```python
x = 2

print(type(x))
```

خروجی:

```text
<class 'int'>
```

در این مثال، نوع `x` برابر با `int` یا عدد صحیح است.

برای یک رشته:

```python
name = "Roya"

print(type(name))
```

نوع متغیر `name` از نوع `str` است.

---

## String

رشته یا `String` برای ذخیره ی متن استفاده می شود.

مثال:

```python
text = "Hello"
```

رشته می تواند شامل چند کاراکتر باشد.

```python
name = "Roya"
```

در این مثال، `name` یک رشته است.

تفاوت مهمی بین عدد و رشته وجود دارد.

```python
x = 1
```

در این حالت `1` یک عدد صحیح است.

اما:

```python
x = "1"
```

در این حالت `"1"` یک رشته است.

پس این دو مقدار از نظر نوع داده با یکدیگر متفاوت هستند.

## عملگرهای حسابی

پایتون از عملگرهای مختلف برای انجام محاسبات ریاضی استفاده می کند.

| عملگر | کاربرد |
|---|---|
| `+` | جمع |
| `-` | تفریق |
| `*` | ضرب |
| `/` | تقسیم |
| `//` | تقسیم صحیح |
| `%` | باقی مانده تقسیم |
| `**` | توان |

### جمع

```python
x = 5

print(x + 2)
```

خروجی:

```text
7
```

### تفریق

```python
x = 5

print(x - 2)
```

خروجی:

```text
3
```

### ضرب

```python
x = 5

print(x * 2)
```

خروجی:

```text
10
```

### تقسیم

```python
x = 5

print(x / 2)
```

خروجی:

```text
2.5
```

### تقسیم صحیح

```python
x = 5

print(x // 2)
```

خروجی:

```text
2
```

### باقی مانده تقسیم

```python
x = 5

print(x % 2)
```

خروجی:

```text
1
```

### توان

```python
x = 5

print(x ** 2)
```

خروجی:

```text
25
```

## استفاده از متغیرها در محاسبات

می توانیم متغیرها را در عملیات ریاضی استفاده کنیم.

```python
x = 5
y = 2

print(x + y)
print(x - y)
print(x * y)
print(x / y)
print(x // y)
print(x % y)
print(x ** y)
```

پایتون ابتدا عملیات را محاسبه می کند و سپس نتیجه را توسط `print()` نمایش می دهد.

## نکته مهم

نوع داده ی یک مقدار مهم است.

برای مثال:

```python
x = 1
```

یک عدد صحیح است.

اما:

```python
x = "1"
```

یک رشته است.

بنابراین همیشه باید به تفاوت بین **عدد** و **رشته ای که شامل عدد است** توجه کنیم.
