# تمرین‌های متغیرها در Python

## تمرین 1 — تعریف متغیر

دو متغیر به نام‌های `x` و `y` ایجاد کنید و به ترتیب مقادیر `10` و `20` را در آن‌ها قرار دهید.

سپس مقدار هر دو متغیر را چاپ کنید.

---

## تمرین 2 — محاسبات با متغیرها

دو متغیر به نام‌های `a` و `b` ایجاد کنید و مقادیر زیر را به آن‌ها بدهید:

- `a = 15`
- `b = 4`

سپس موارد زیر را با استفاده از `print()` نمایش دهید:

1. جمع
2. تفریق
3. ضرب
4. تقسیم
5. تقسیم صحیح
6. باقی‌مانده
7. توان

---

## تمرین 3 — تشخیص نوع متغیر

متغیرهای زیر را ایجاد کنید:

```python
age = 25
name = "Roya"
```

سپس نوع هر دو متغیر را با استفاده از `type()` بررسی و چاپ کنید.

---

## تمرین 4 — عدد و رشته

دو متغیر زیر را ایجاد کنید:

```python
number = 1
text = "1"
```

نوع هر دو متغیر را چاپ کنید.

سپس مشخص کنید کدام‌یک عدد صحیح و کدام‌یک رشته است.

## تمرین 5 — محاسبه داخل print

بدون ایجاد متغیر جدید، عبارت‌های زیر را مستقیماً داخل `print()` محاسبه کنید:

```text
8 + 4
10 - 3
6 * 5
20 / 4
20 // 3
20 % 3
2 ** 4
```

## تمرین 6 — ساخت متغیر جدید از متغیرهای قبلی

دو متغیر زیر را ایجاد کنید:

```python
x = 12
y = 8
```

سپس یک متغیر جدید به نام `sum_result` ایجاد کنید که حاصل جمع `x` و `y` باشد.

در پایان مقدار `sum_result` را چاپ کنید.
