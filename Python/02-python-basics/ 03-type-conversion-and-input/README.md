# Type Conversion and Input

در این بخش با تبدیل نوع داده ها و دریافت ورودی از کاربر در Python آشنا می شویم.

---

## 1. تبدیل رشته به عدد با `int()`

تابع `int()` یک مقدار را به عدد صحیح تبدیل می کند.

```python
x = "123"

x = int(x)

print(x)
print(type(x))
```

خروجی:

```text
123
<class 'int'>
```

اگر یک رشته شامل عدد باشد، می توانیم آن را با `int()` به عدد صحیح تبدیل کنیم.

---

## 2. تفاوت String و Number

این دو مقدار با یکدیگر تفاوت دارند:

```python
x = 100
y = "100"
```

`x` یک عدد صحیح است، اما `y` یک رشته است.

برای مثال:

```python
print(100 * 2)
print("100" * 2)
```

خروجی:

```text
200
100100
```

بنابراین نوع داده روی نحوه ی انجام عملیات تأثیر می گذارد.

---

## 3. تبدیل عدد اعشاری با `float()`

برای تبدیل یک مقدار به عدد اعشاری از `float()` استفاده می کنیم.

```python
x = "2.5"

x = float(x)

print(x)
print(type(x))
```

خروجی:

```text
2.5
<class 'float'>
```

---

## 4. تبدیل به رشته با `str()`

تابع `str()` یک مقدار را به رشته تبدیل می کند.

```python
x = 123

x = str(x)

print(x)
print(type(x))
```

خروجی:

```text
123
<class 'str'>
```

---

## 5. تبدیل کد ASCII به کاراکتر با `chr()`

تابع `chr()` یک عدد را به کاراکتر متناظر آن تبدیل می کند.

```python
print(chr(98))
```

خروجی:

```text
b
```

---

## 6. تبدیل کاراکتر به کد ASCII با `ord()`

تابع `ord()` کد عددی یک کاراکتر را برمی گرداند.

```python
print(ord("b"))
```

خروجی:

```text
98
```

بنابراین:

```text
ord("b") → 98
chr(98) → "b"
```

---

## 7. گرد کردن با `round()`

برای گرد کردن اعداد از `round()` استفاده می کنیم.

```python
x = 5.58

print(round(x))
```

همچنین می توانیم تعداد رقم های اعشار را مشخص کنیم:

```python
x = 5.586

print(round(x, 2))
```

خروجی:

```text
5.59
```

---

## 8. تابع `divmod()`

تابع `divmod()` خارج قسمت و باقی مانده ی تقسیم را با هم برمی گرداند.

```python
result = divmod(10, 3)

print(result)
```

خروجی:

```text
(3, 1)
```

یعنی:

```text
خارج قسمت = 3
باقی مانده = 1
```

---

## 9. تابع `pow()`

برای محاسبه ی توان می توانیم از `pow()` استفاده کنیم.

```python
print(pow(2, 3))
```

خروجی:

```text
8
```

معادل:

```python
2 ** 3
```

است.

---

## 10. گرفتن ورودی با `input()`

برای دریافت اطلاعات از کاربر از `input()` استفاده می کنیم.

```python
name = input("Enter your name: ")

print(name)
```

کاربر مقدار موردنظر خود را وارد می کند و این مقدار داخل متغیر `name` قرار می گیرد.

---

## 11. نکته مهم درباره `input()`

در Python 3، مقدار دریافت شده توسط `input()` به صورت `str` ذخیره می شود.

مثلاً:

```python
age = input("Enter your age: ")

print(type(age))
```

حتی اگر کاربر عدد `25` را وارد کند، نوع مقدار دریافت شده:

```text
<class 'str'>
```

است.

---

## 12. تبدیل ورودی به عدد صحیح

اگر بخواهیم ورودی کاربر را به عدد صحیح تبدیل کنیم:

```python
age = int(input("Enter your age: "))

print(age)
print(type(age))
```

حالا می توانیم روی مقدار دریافت شده عملیات ریاضی انجام دهیم.

مثال:

```python
number = int(input("Enter a number: "))

print(number * 2)
```

---

## 13. تبدیل ورودی به عدد اعشاری

اگر کاربر قرار است یک عدد اعشاری وارد کند، از `float()` استفاده می کنیم.

```python
number = float(input("Enter a number: "))

print(number / 2)
```

مثلاً اگر کاربر وارد کند:

```text
2.5
```

خروجی:

```text
1.25
```

---

## 14. تبدیل عدد در مبناهای مختلف

تابع `int()` می تواند یک رشته ی عددی را با مشخص کردن مبنا به عدد صحیح تبدیل کند.

مثلاً:

```python
number = int("101", 2)

print(number)
```

خروجی:

```text
5
```

در این مثال `"101"` در مبنای 2 قرار دارد و مقدار آن در مبنای 10 برابر با `5` است.

---

## جمع بندی

در این بخش با موارد زیر آشنا شدیم:

- `int()` برای تبدیل به عدد صحیح
- `float()` برای تبدیل به عدد اعشاری
- `str()` برای تبدیل به رشته
- `chr()` برای تبدیل کد عددی به کاراکتر
- `ord()` برای تبدیل کاراکتر به کد عددی
- `round()` برای گرد کردن
- `divmod()` برای به دست آوردن خارج قسمت و باقی مانده
- `pow()` برای محاسبه ی توان
- `input()` برای دریافت ورودی از کاربر
- تبدیل ورودی `input()` به `int` و `float`
- تبدیل اعداد بین مبناهای مختلف با `int()`

### نکته کلیدی

مقداری که با `input()` دریافت می کنیم، به صورت `str` است.

پس اگر قرار است روی ورودی عملیات ریاضی انجام دهیم، باید نوع آن را تبدیل کنیم:

```python
number = int(input("Enter a number: "))
```

یا:

```python
number = float(input("Enter a number: "))
```
